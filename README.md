# 👨‍💼 Employee Management System

A simple **console-based Employee Management System built with Python**.

## 📌 Project Overview

This project is designed to manage employee records through a simple menu-driven program.

Each employee record contains:

* Name
* Age
* Department
* Salary

## ✨ Features

* ➕ Add Employee
* 📋 Show Employees
* 🔍 Search Employee
* 🗑️ Delete Employee
* ✏️ Update Employee Salary
* 🚪 Exit

## 🧠 Concepts Used

* Variables
* Input
* Lists
* Dictionaries
* Loops
* Functions
* Conditions

## 🛠️ Technology

* Python 3

## ▶️ How to Run

Make sure Python 3 is installed.

Run:

```bash
python employee_management_system.py
```

## 📋 Main Menu

```text
1. Add Employee
2. Show Employees
3. Search Employee
4. Delete Employee
5. Update Employee
6. Exit
```
